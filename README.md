# Trigger Trove
A compilation of triggers to use with the [Trigger Engine](https://github.com/reonZ/trigger-engine) module.

> [!WARNING]
> This module has been retooled to use **Trigger Engine** instead of PF2e Trigger. Make sure you have the right module enabled. PF2e Trigger will not be supported by this module as of version 1.0.0

## How to use?
Enable the module and you will see our compilation of triggers. They are **disabled** by default, and you should only enable triggers that you plan on using.

If you want to see what rules have triggers, you can navigate the [triggers](./triggers/) directory.
